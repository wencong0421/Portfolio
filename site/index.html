About Me

Hello,
I'm Ivan!

Business Analyst who works like a data engineer. I'm the first in-house BA and sole owner of the Power BI and Microsoft Azure data platform at a multi-country F&B retail group, from data ingestion and SQL warehousing to the reports leadership reviews every morning.

I'm happiest when something is broken in production and nobody knows why. I've traced a silent six-week pipeline failure, rebuilt authentication after a Microsoft retirement took down a forecast system, and reconciled a ~2.5% revenue gap between Power BI and the point-of-sale record. I also automate the manual work around it with SQL, DAX, Python and Power Automate.

I graduated with a dual-award Business Analytics degree (Second Class Honours, Division One) from Sunway and Lancaster University. What I care about most is data people can trust, and the engineering that keeps it that way.

Notable Projects

01

Enterprise Data Platform Recovery

The automated weekly forecast pipeline, used by Operations, Production and Purchasing, went down for about 3.5 weeks after Microsoft retired a legacy SharePoint authentication method. I root-caused it, migrated to certificate-based Microsoft Entra ID authentication and redeployed the Azure Functions myself via Cloud Shell.

Result: Automated operations restored after weeks of manual fallback.

  • Azure Functions
  • Entra ID
  • SharePoint
  • Cloud Shell
02

Silent Pipeline Failure and Category Repair

A Synapse pipeline had failed silently for six weeks, corrupting product-category data across the company. I isolated the fix on its own Git branch, validated it through PR review, then released it to production.

Result: Data integrity restored across the full retail product catalog.

  • Azure Synapse
  • T-SQL
  • Git
  • Azure DevOps
03

Revenue Reconciliation: Power BI vs POS

Power BI was under-reporting revenue by about 2.5% against the point-of-sale system of record. I traced the gap to hard-coded category exclusions in a SQL script and introduced a governed category-mapping standard, plus a bill-and-item-level method for checking any future discrepancy.

Result: Numbers reconciled, with a standard that stops the gap returning.

  • Power BI
  • Azure SQL
  • Data governance
04

Multi-Branch DAX and Row-Level Security

Built disconnected calculated tables and TREATAS-based cross-domain slicer logic so branch filtering and RLS behave consistently across 25+ branches, even where fact and dimension coverage didn't match.

Result: One governed model, extended to a newly onboarded outlet.

  • DAX
  • TREATAS
  • RLS
  • Data modeling
05

From Manual Reporting to Automation

A Python and Google Colab pipeline consolidated 72 historical forecast files (2024–2026, four formats) into one governed dataset for Synapse and Power BI. A manual Excel sales report with 863 cached formula errors became an auto-refreshing dashboard, backed by a 53-sheet data dictionary of 45+ pipelines and 49 SQL tables.

Result: A fully manual quarterly workflow eliminated, and the platform documented from scratch.

  • Python
  • Pandas
  • Power BI
  • Documentation
06

Asset Portfolio System and GenAI Tools

At Rimbun Capital I designed the Dataverse schema for a central tracker of high-value assets and built Power BI dashboards on top. I also prototyped a ChatGPT Enterprise legal assistant for Corporate Recovery documents and an OCR pipeline that pulls balance-sheet figures out of SSM PDF filings.

Result: Management can spot underperforming assets; less manual research and data entry.

  • Dataverse
  • Power BI
  • AI Builder
  • Power Automate
  • BRDs
07

Loyalty Analytics, Built From Scratch

Marketing had membership data locked in a loyalty platform with no reporting. I built the whole path: API extraction on Azure Functions (Flex Consumption) with Key Vault and managed identity, ADLS and Synapse serverless SQL, a Power BI semantic model and an 8-page dashboard, kept separate from the daily sales pipeline.

Result: Member, tier and fraud-control insight refreshed every morning, after validating join keys against POS data.

  • Azure Functions
  • Synapse serverless
  • Key Vault
  • Power BI
  • Python
08

Azure Cost Review

With the vendor gone, nobody was watching cloud spend. I reviewed every resource, retired an idle machine-learning workspace and unused pipelines, and planned SQL pool schedule and Function App changes, holding anything cost-impacting until it was formally approved.

Result: A phased plan to cut monthly platform cost by about 70%.

  • Azure
  • Synapse
  • Cost governance
  • Change control
09

Alford: Web-Based Power BI Reporting System (Final Year Project)

An automated reporting system that brings web-based data into Power BI. I built the full web application (HTML, CSS, JavaScript) and deployed it on Netlify myself, and co-developed the Power BI reports with a teammate. It's also why this portfolio is hosted the same way.

  • HTML
  • CSS
  • JavaScript
  • Power BI
  • Netlify
